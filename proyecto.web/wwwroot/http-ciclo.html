Decisiones preventivas

Convierte lo que detecta el modelo en acciones concretas de concientización para las áreas expuestas.

  1. 1
    Detectar

    El modelo HDBSCAN identifica accesos HTTP que no encajan en los patrones habituales.

  2. 2
    Confirmar

    Un administrador revisa el comportamiento en «Comportamientos atípicos» y lo confirma como incidente, o se confirma un reporte del personal.

  3. 3
    Decidir

    Aquí aparece una sugerencia por área y tema: lanza una simulación, asigna una microlección o descártala con una nota.

Sugerencias por atender

Se crean cuando un analista confirma una anomalía HTTP como incidente o cuando se confirma un incidente real reportado por el personal. Las evidencias de la misma sucursal y área se agrupan durante 30 días. El sistema solo sugiere: tú decides.

Validar el modelo con simulaciones

Herramienta técnica. Las simulaciones de phishing generan tráfico HTTP de origen conocido que sirve para comprobar cómo responde el modelo.

Cada apertura, clic y envío del formulario señuelo queda registrado como petición HTTP real, con la IP y el token seudonimizados. Genera un archivo NGINX de una campaña y analízalo en Fuentes y registros como cualquier otro conjunto.
